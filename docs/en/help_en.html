1. What Is This App For

Xizhen is a place to help you think one thing through, continuously. Through structured breakdown, ongoing recording and revision, it improves your understanding of things.

Every day we think about things: whether someone is reliable, where a project's risks lie, whether a decision should be made, what a concept really means. But most of the time, these thoughts are scattered — once thought, they're forgotten; when they change, we don't know why; what we've figured out can't be kept.

Xizhen's purpose is to give your thinking structure, a trace, and continuity.

It doesn't judge for you, and it doesn't promise you answers. It helps you do four things:

  • Break it down: Use "Overall," "Perspectives," and "Analysis Points" to break something apart and look at it from multiple angles, instead of facing a tangled mess.
  • Keep it: Mark what you haven't figured out yet, record how your judgments change, so that what you've thought isn't wasted.
  • Approach: Keep revising and saving versions, and see how your understanding has evolved along the way — getting closer and closer to reality.
  • Form an overall understanding: Combine judgments from different perspectives into an overall view of the object, rather than scattered points.

It's suited to these uses:

  • Tracking one thing over the long term and thinking it through. For example, a subject you're studying or a topic you're researching.
  • Quickly analyzing a batch of similar objects using templates. For example, when you have many similar objects to analyze thoroughly, recording them and using templates makes it much easier.
  • Seeing the many people and things in your environment more clearly. For example, if you want to regularly analyze the world around you, whether abstract or concrete.
  • Analyzing things that have a process and a timeline. Perspectives and analysis points can both be organized as time periods; a perspective within an object can be duplicated to become a new perspective, and analysis points can be duplicated too.

What it is not:
Not a note-taking app, not a task manager, not a collaboration tool, not a knowledge base, and not a knowledge graph. It does one thing: it carries your ongoing understanding of things.

In one sentence: This app gives people who need to keep thinking things through a structured analysis tool.

This app is a standalone, offline application. It does not support multi-device sync, does not connect to the internet, and does not collect any user data — except when viewing the help documentation (standard HTML browsing), when the user manually initiates a feedback email (using the system email app, which only collects device model, iOS version, app version, and app operation log files; log files contain no user content), and when viewing the privacy policy and user agreement (using the system browser).

2. What Is an Object

Object structure: An object consists of an Overall section and multiple Perspectives. The Overall section carries the main understanding of the object being analyzed. A Perspective contains multiple Analysis Points. This three-level structure — Overall → Perspective → Analysis Point — is how we record our analysis.

An Analysis Point is where you record a specific piece of content. It consists of a Summary and a Body. The Summary lets you quickly grasp the topic and conclusion of the analysis point. The Body contains multiple content blocks.

In one sentence: Create an object first, then add perspectives, then fill in analysis points; if you have an overall view, write it in the Overall section.

3. Suggested First Steps

  1. Tap the + at the bottom center to create an object. Give it any name.
  2. Don't rush to write yet. Tap + in the "Perspectives" row to add two or three perspectives.
  3. Switch to a perspective, and tap + in the "Analysis Points" row to create an analysis point.
  4. Tap into the analysis point and start writing. The first block is the Summary — write a one-sentence overview; then add the blocks you need in the Body below.
  5. You don't need to build everything at once. Adding as you think is the normal way to use it.

4. How to Add Content Blocks

When writing an analysis point, the "Add" row at the bottom offers various content blocks:

  • Text: The most common. Tapping it opens a full-screen editor where you can bold, underline, color, link, add ordered lists, and insert inline markers like [Conclusion] and [Rule].
  • Image: From your photo library or camera.
  • Table: Row and column editing, good for comparisons.
  • Audio: For voice notes.
  • Whiteboard: Handwriting, for sketching.

Long-press a content block to: move up, move down, add a title, add an annotation, or delete.

Adding a title to a content block: When you create a new content block, a title row appears. If you type something, it's kept; if you don't, it disappears. To add one later, use the menu.

Annotations: Add marks to places you consider special or noteworthy. There are two kinds: text annotations and block annotations.

  • Text annotations: Located inside the rich-text editor.
  • Block annotations: Displayed above the block.

5. Templates

Save frequently repeated structures as templates.

  • Long-press an analysis point → "Save as Content Template."
  • Object menu → "Save as Object Template."
  • Next time you create something, choose an object template or content template directly. A content template can serve as the template for an object's Overall section.

The point of templates is to help us analyze thoroughly, reducing repetition and omissions.

Some system templates are provided by default (they may be updated between versions). They cannot be edited, but can be saved as your own templates.

6. Methods

The point of methods: Write down analysis approaches, thoughts, and things to watch out for regarding a certain type of thing. Methods carry cognitive experience and cognitive approaches. They are not knowledge points, nor are they viewpoints about a specific object.

A method can be linked to an object, a perspective, an analysis point, or the Overall section.

  • Methods live independently in a method library; they can only be modified there.
  • Linked locations can only view, reference, or unlink them.
  • Change it once, and it updates everywhere.

Some system methods are provided by default (they may be updated between versions). They cannot be edited, but can be saved as your own methods.

7. Object Versions and Revision History

Manually save a version at important milestones. Afterwards, you can view historical versions and restore them.

Revision history: Gives a rough view of how the content has changed over time.

Together, these let you look back and see how your understanding of things changed, and when you made those changes.

8. Categories

Once you have many objects, use the "Categories" button on the left to create categories.

  • Multiple levels are supported.
  • Long-press a category to rename, move, or delete it.
  • When deleting a category, you'll be asked: move the objects inside to the root, or delete them together.

9. Trash

Objects, templates, and methods all go to the Trash when deleted.

You can restore them from the Trash. Items in the Trash are periodically cleared (30 days by default).

10. Auxiliary Features

Exporting Objects

  • Long-press or multi-select in the list → "Export."
  • For sensitive content, we recommend encrypted export.

Full Backup and Restore

  • Settings → Data Backup.
  • Includes all data; restoring overwrites the current device.
  • You can back up before switching phones and copy the backup off the phone; after setting up the new phone, restore from the backup.

Security Settings

  • Settings → Security Settings.
  • When enabled, data on the device is stored as ciphertext.
  • A single text password derives the key that decrypts the data.
  • When enabling, you'll be given a recovery key. Write it down on paper and keep it offline. If you forget your password, it is the only way back.
  • Once enabled, you'll need to enter the password when launching the app or returning from the background.

11. A Few Practical Tips

  • Create the object before worrying about structure — don't overthink how to divide perspectives at the start.
  • One sentence for the summary is enough; expand in the body.
  • Save repeated structures as templates — faster than rebuilding each time.
  • Save versions at important milestones so you can roll back if something breaks.
  • Write the recovery key on paper — don't put it in a notes app, don't screenshot it.
  • Export a full backup regularly and store it on your computer or cloud drive.
  • Mark your doubts — the app will remind you where you haven't thought things through.

12. Need Help? Send Feedback

  • Settings → Help (this page).
  • Settings → Feedback. You can attach images, files, and logs, sent via the system email app.
  • We collect basic information to help diagnose issues: device model, OS version, app version, and operation log attachments. You can also manually add images, system crash log files, etc. We do not read any of your content data.

FAQ:

  • Forgot your password: restore with the recovery key. If the recovery key is lost and the password is forgotten, the data cannot be recovered.
  • Exported files with "no encryption" selected: anyone who gets the file can read it.
  • System templates are read-only: to modify one, "Duplicate as" your own.
