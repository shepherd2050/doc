析真 · 帮助文档

一、这个 App 是做什么的

析真，是一个让你把一件事持续想清楚的地方。通过结构化拆解、持续记录和修改，提升对事物的认知。

我们每天都在琢磨事情：一个人靠不靠谱、一个项目风险在哪、一个决定该不该做、一个概念到底是什么意思。但大多数时候，这些琢磨是散的——想过就忘了，变了不知道为什么变，想清楚的东西留不住。

析真的目的，是让琢磨有结构、有痕迹、能持续。

它不替你判断，也不承诺给你答案。它帮你做四件事：

  • 拆开：用「总体」「角度」「分析点」把一个东西拆开，从多个面看它，而不是一团乱麻。
  • 留下：标出还没想清楚的地方，记下判断的变化，让想过的东西不白想。
  • 逼近：持续修改、保存版本，看见自己的认知怎么一路变过来，越来越接近真实。
  • 形成总体认知：把各个角度的判断合起来，形成对这个对象的整体看法，而不只是散落的点。

它适合这些用途：

  • 长期跟踪一件事，把它琢磨透。例如你正在学习一个科目、研究一个课题。
  • 用模板快速分析一批同类对象。例如你要分析的同类对象较多，都要好好分析，这时记录下来，采用模板等就很方便。
  • 看清自己所处环境里的众多人和事。例如你想定期分析自己周围的世界，不论抽象的还是现实的。
  • 分析有过程、有时间线的事情。角度和分析点都可以作为时间段来组织；对象内的角度可以复制一份，成为一个新角度，分析点也可以复制。

它不是什么？
不是笔记软件，不是日程管理，不是协作工具，不是知识库，也不是知识图谱。它只做一件事：承载你对事物的持续认知。

一句话：本 App 是给需要持续琢磨的人，提供一个结构化分析工具。

本 App 是单机应用，不支持多设备同步，不联网，不采集任何用户数据。 除了看帮助文档（标准的 HTML 浏览）、用户手动发起反馈邮件（用系统邮件 App，只采集设备型号、iOS 版本号、App 版本号、App 操作日志文件，日志文件不含任何用户内容）、看隐私政策和用户协议（用系统浏览器）之外。

二、什么是对象

对象的结构：一个对象包括总体和多个角度。总体承载了对分析对象的主要认知。一个角度包括多个分析点。这样以总体—角度—分析点的三级结构，来记录我们的分析。

分析点是对具体的一个内容进行记录的地方。分析点包括摘要和正文。摘要让我们快速了解这个分析点的主题和结论。正文包括多个内容块。

一句话：先建对象，再切角度，再填分析点；如果有总体观点，就在总体中填写。

三、第一次用，建议这么走

  1. 点底部中间的 +，建一个对象，随便起个名字。
  2. 进去后先别急着写，在「角度」那一排点 +，建两三个角度。
  3. 切到某个角度，在「分析点」那一排点 +，建分析点。
  4. 点进分析点，开始写。第一个块是摘要，写一句话概括；下面的正文里加你需要的块。
  5. 不用一次建全。边想边加，是正常用法。

四、怎么添加内容块

写分析点时，下方「添加」那一排是各种内容块：

  • 文本：最常用。点进去是全屏编辑器，可以加粗、下划线、颜色、链接、有序列表，也能插【结论】【规则】这类段内标记。
  • 图片：相册或拍照。
  • 表格：行列编辑，适合对比。
  • 录音：口述用。
  • 白板：手写，画草图。

内容块可以长按：上移、下移、加标题、加标注、删除。

内容块加标题：新建内容块时会出现标题行，输入即保留，不输入就消失。以后想加，从菜单添加。

标注：在认为比较特殊、值得注意的地方加入标记，分为文本标注和块标注。

  • 文本标注：位于富文本编辑框内部。
  • 块标注：添加到块显示的上方。

五、模板

经常重复的结构，存成模板。

  • 分析点长按 →「另存为内容模板」。
  • 对象菜单 →「另存为对象模板」。
  • 下次新建时直接选对象模板或者内容模板。内容模板可以作为创建对象时的总体的模板。

模板的意义是让我们能全面分析，减少重复和减少遗漏。

系统默认有部分系统模板（版本变化可能会更新），不可编辑，可另存为自己的模板。

六、方法

方法的意义：填写对某类事物的分析方法、思考、注意事项等等。方法承载的是认知经验、认知方法。方法不是知识点，也不是具体的对象的观点。

方法可以关联到对象、角度、分析点或总体上。

  • 方法独立成库，只在方法库修改。
  • 挂载点只能查看、引用、解除。
  • 改一处，处处同步。

系统默认有部分系统方法（版本变化可能会更新），不可编辑，可另存为自己的方法。

七、对象的版本和修改历史

重要节点手动保存一个版本，之后可以查看历史版本、恢复。

修改历史：可以大致看到内容变化过程。

这两者让我们可以回头看到自己对事物的认知变化，什么时间作出了改变。

八、分类

对象多了以后，用左侧「分类」按钮建分类。

  • 支持多级。
  • 长按分类可以改名、移动、删除。
  • 删除分类时会问你：把里面的对象移到根目录，还是一起删。

九、回收站

对象、模板和方法，都支持删除后进入回收站。

可以从回收站中恢复。回收站内的对象、模板和方法，会被定期清除（默认 30 天）。

十、辅助功能

导出对象

  • 列表长按或多选 →「导出」。
  • 敏感内容建议加密导出。

整体备份恢复

  • 设置 → 数据备份。
  • 包含全部数据，恢复时覆盖当前设备。
  • 可以在更换手机前备份，拷贝到手机之外；新手机安装好后，用备份的数据恢复。

安全设置

  • 设置 → 安全设置。
  • 开启后，数据在设备上是密文。
  • 一个文字密码，派生密钥，解密数据。
  • 开启时会给一串恢复密钥。请抄在纸上，离线保存。忘记密码时，它是唯一出路。
  • 开启后，启动应用或者从后台返回，需要输入密码。

十一、几条实际建议

  • 先建对象再想结构，不要一开始纠结角度怎么分。
  • 摘要一句话就够，正文里再展开。
  • 重复的结构存模板，比每次重搭快。
  • 重要节点存版本，改坏了能回。
  • 恢复密钥抄纸上，别放备忘录、别截图。
  • 定期导出完整备份，存到电脑或网盘。
  • 存疑标出来，它会提醒你哪里还没想清楚。

十二、有问题看帮助，请反馈

  • 设置 → 帮助（就是这页）。
  • 设置 → 反馈，可以附图片、文件、日志，通过系统邮箱发送。
  • 这里我们会采集基础信息辅助定位问题：设备型号、系统版本、App 版本、操作日志附件。你也可以手动添加图片、系统崩溃日志文件等。我们不会读取任何用户的内容数据。

常见问题：

  • 忘记密码：用恢复密钥恢复。恢复密钥丢失且忘记密码，数据永久无法恢复。
  • 导出的文件选“不加密”：任何拿到文件的人都能读。
  • 系统模板只读：想改就「复制为」自己的。
